## 📖 About the Project

The **Personal Finance Tracker** is a C++ application that helps users manage their income and expenses through an interactive menu-driven interface. It supports adding income/expense transactions, viewing all records, generating a financial summary with smart suggestions, and exporting expense data to a file which is then consumed by a Python script to generate a **pie chart visualization**.

---

## ✨ Features

- **Add Income** — Record income with date, category, amount, description, and source (e.g., Salary, Freelance)
- **Add Expense** — Record expenses with date, category, amount, description, and payment method (Cash/Card/UPI)
- **View All Transactions** — Display all income and expense records with full details
- **Financial Summary** — View total income, total expenses, and net savings
- **Smart Suggestions** — AI-style financial advice based on your spending ratio:
  - Warning if expenses exceed income
  - Caution if spending exceeds 80% of income
  - Positive feedback if saving more than 50% of income
- **Expense Breakdown** — Category-wise expense analysis with percentage share
- **File Export** — Saves expense data to `expense_data.txt` for use by the Python chart generator
- **Pie Chart Visualization** — Python notebook reads the exported data and generates a pie chart (`expense_piechart.png`)

## 🧩 OOP Concepts Used

| Concept | How It's Applied |
|---|---|
| **Encapsulation** | Transaction data (date, category, amount, description) is kept private/protected; accessed via public methods |
| **Inheritance** | `Income` and `Expense` both inherit from the base class `Transaction` |
| **Polymorphism** | `display()` method is overridden in `Income` and `Expense` to show type-specific details |
| **Abstraction** | `Suggestion` base class defines a generic `suggest()` interface; `SmartSuggestion` provides the real implementation |
| **Dynamic Dispatch** | `virtual` keyword enables runtime polymorphism for `display()` and `suggest()` |
| **Dynamic Memory** | Transactions are stored as `Transaction*` pointers; memory is freed in the `ExpenseManager` destructor |

## 🏗️ Class Architecture

```
Transaction  (Base Class)
├── date, category, amount, description  (protected)
├── display()  (virtual)
├── getAmount(), getCategory()
│
├── Income  (Derived)
│   ├── source  (private)
│   └── display()  (override) → prints [INCOME] with source
│
└── Expense  (Derived)
    ├── paymentMethod  (private)
    └── display()  (override) → prints [EXPENSE] with payment method

Suggestion  (Base Class)
└── suggest(income, expense)  (virtual)
    └── SmartSuggestion  (Derived)
        └── suggest()  (override) → conditional financial advice

ExpenseManager
├── records : vector<Transaction*>
├── addTransaction()
├── showAll()
├── totalIncome()
├── totalExpense()
├── showExpenseBreakdown()
└── saveExpenseData()  → writes to expense_data.txt
```

## ▶️ How to Run

### Prerequisites
- A C++ compiler (g++ recommended)
- Python 3.x with `pandas` and `matplotlib` installed (for chart generation)
- Jupyter Notebook or Google Colab (for running the `.ipynb` file)

### Compile & Run the C++ Program

```bash
g++ Personal_finance_tracker_OOP_C++.cpp -o finance_tracker
./finance_tracker
```

### Generate the Pie Chart (Python)
After running the C++ program and using **Option 5** to export data:

```bash
jupyter notebook Filehandling_python.ipynb
```

Or run in **Google Colab** — upload both files and run all cells.

---

## 🥧 Python Chart Integration

The `Filehandling_python.ipynb` notebook:

1. Reads `expense_data.txt` (generated by the C++ program)
2. Parses it as a CSV with `Category` and `Amount` columns using `pandas`
3. Generates a color-coded pie chart using `matplotlib`
4. Saves the chart as `expense_piechart.png`
5. Displays the chart inline
